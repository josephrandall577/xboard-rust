# 单端口独立 PSK 验证

节点使用面板用户 UUID 作为该用户的 PSK，只接受 Snell v6 default shaped 模式。
指纹负责选择凭据；只有首记录 AEAD 验证成功后才能确定身份。请求中的
client_id 无法改变认证用户或计费用户。每个入站首记录只对选定 PSK 派生一次密钥。

## 首包读取与约束

- 先读 32 字节，再按 16 字节步进，最多读取 144 字节。
- 每一步检查新覆盖到的全部实际块长度。Profile 的块长度并不限定为 16 的倍数。
- 指纹保留所有固定字节，恰好忽略 16 个 salt 位置，至少比较 16 个固定字节。
- 最多多读 15 字节，通过 PrefixedConn 回灌；ShapedReader 从 salt 已消费状态开始。
- PSK 唯一且为 12–255 字节；非法更新保持原凭据集。空用户集撤销所有凭据。
- 用户快照预先检查所有指纹对，包括不同块长度、不同 salt 位置。只有双方共有的
  固定位置存在不同字节时，才能证明不会同时匹配；否则保守拒绝整个快照。
  轮询和 WebSocket 均在写入数据库前验证，协议服务也在原子替换前再次验证。
  两两检查的更新开销为 O(N²)，不增加连接路径上的两两检查。
- 有界重放缓存按 PSK 隔离，只写入通过 AEAD 验证的 salt；用户更新不清空缓存。
  缓存不持久化，重启或容量轮换后不再保留旧的重放记录。

不能仅凭“比较了 16 个固定字节”保证真实 Profile 之间的误匹配率为 2⁻¹²⁸：
shaped 填充并非均匀随机。误选凭据仍必须通过 AEAD 验证，失败时关闭连接，
不会回退到 client_id 认证或逐个候选 PSK 试解密。

## 未认证连接资源限制

每个节点独立使用 `[limits]` 配额，旧配置省略时采用以下默认值：

```toml
[limits]
max_handshakes = 256
max_handshakes_per_ip = 32
handshake_timeout = 10
```

在创建连接任务前同步预留配额，超额连接立即关闭，不排队等待。超时预算从接纳
连接时开始，部分首包不会续期。首记录 AEAD 验证完成即释放配额，已有转发连接
不计入；失败、超时、任务取消和丢弃未执行的任务也会释放。IPv4-mapped IPv6 与
对应 IPv4 地址共用来源桶，来源端口不参与计数。没有 IP 的库调用共用一个桶。

共享 NAT 下可提高 `max_handshakes_per_ip`，设为 0 只关闭每 IP 限制；全局上限和
超时必须大于 0。此处限制并发握手数，不限制每秒连接数，也不限制已认证连接总数。

新增回归覆盖：同长度/跨长度及 salt 通配位置的指纹歧义、更新失败保留原快照、
克隆服务共享配额、独立节点配额隔离、映射地址归一化、慢连接绝对超时、延迟执行、
任务取消、无效 AEAD/截断首包释放配额，以及认证后响应阻塞时仍释放配额。
节点真实 TCP 监听测试还检查超额连接立即关闭、慢连接超时后新的转发恢复。

## 已执行验证

- 1000 个 Profile 的长度、固定字节及 salt 通配位置。
- 分片首包、32+16 字节读取步进、非对齐块长度及多读字节回灌。
- 空 client_id、伪造 client_id、未知 PSK、篡改首记录和截断首包。
- 重放拒绝、无效 AEAD 不污染重放缓存、缓存按用户隔离。
- 密钥轮换、清空用户及同一 TCP 连接复用后的凭据撤销。
- 真实本地节点 TCP/UDP 转发、限速及按 PSK 所属用户计费。
- 独立 Go 参考客户端的 TCP/UDP 与精确面板流量报告。

| 项目 | 结果 |

| 1000 用户完整指纹扫描 | 2.338 µs |

6.634 ms、面板快照预验证 6.681 ms、已有凭据集更新 3.691 ms、完整指纹扫描
1.247 µs。预验证与服务更新是两个独立阶段，面板同步会执行两者；扫描路径仍只

## 指纹歧义的恢复

指纹用于选择首次 AEAD 验证的候选凭据。即使 UUID 不同，若其指纹存在歧义，
节点仍会拒绝整个新快照并继续使用上一份有效凭据，防止候选误选。
遇到此错误应重新生成本次新增或修改用户的 UUID 后重试；不要关闭歧义检查，
也不要把 UUID/PSK 写入诊断日志。
